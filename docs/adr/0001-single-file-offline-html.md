# Single-file offline HTML output

Status: accepted

Each **Guide** compiles into one self-contained, offline-ready HTML file with zero backend, accounts, or live AI server dependencies. We chose single-file portability over a hosted web app with cloud sync or a live AI tutor so guides open instantly on any phone, laptop, or Canvas artifact with zero setup and no network friction. All ADHD reading aids, interactive visuals, and learner progress must live inside the static bundle and local browser storage.
