# Calm, guilt-free feedback over gamification clutter

Status: accepted

Learner motivation relies strictly on instant, calm, non-punitive feedback—crisp checkmarks, smooth metro-track progress fills, subtle optional celebrations on **Station** or **Checkpoint** completion, and encouraging explanations on wrong guesses. We explicitly exclude countdown timers, streak-loss penalties, XP points, leaderboards, and auto-playing sound effects. Many ADHD study tools default to gamification hooks, but timers and streak penalties trigger anxiety and distraction rather than sustained focus.
